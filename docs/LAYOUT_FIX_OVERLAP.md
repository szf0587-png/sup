# 模块布局优化 - 修复与侧边栏重叠问题

## 🐛 问题描述

**地块精评**和**智能决策报告**两个模块的内容与左侧工具栏重叠。

### 问题原因
这两个模块的左侧边距设置为 `left: 80px`，这个距离太小，导致内容与左侧工具栏（宽度约 240-280px）重叠。

---

## ✅ 解决方案

### 修改内容
将两个模块的左侧边距从 `80px` 调整为 `320px`。

### 修改详情

#### 1. 地块精评模块
**修改位置**: 行 ~1070

**修改前**:
```html
<div class="absolute right-6 bottom-6 z-10 flex flex-col gap-4 overflow-y-auto pr-2 pb-4" 
     style="top:128px;left:80px;" 
     id="parcel-eval-container">
```

**修改后**:
```html
<div class="absolute right-6 bottom-6 z-10 flex flex-col gap-4 overflow-y-auto pr-2 pb-4" 
     style="top:128px;left:320px;" 
     id="parcel-eval-container">
```

---

#### 2. 决策报告模块
**修改位置**: 行 ~1198

**修改前**:
```html
<div class="absolute right-6 bottom-6 z-10 flex flex-col gap-4 overflow-y-auto pb-4" 
     style="top:128px;left:80px;pointer-events:none;">
```

**修改后**:
```html
<div class="absolute right-6 bottom-6 z-10 flex flex-col gap-4 overflow-y-auto pb-4" 
     style="top:128px;left:320px;pointer-events:none;">
```

## 🎯 边距计算

### 左侧工具栏宽度分析
```
移动端 (md:w-16):  64px
桌面端 (md:w-64):  256px (实际约 240-280px 含 padding)
```

### 推荐的左边距
```
安全边距: 320px
= 工具栏宽度 (280px) + 间隙 (40px)
```

### 为什么选择 320px？
1. **避免重叠**: 280px（工具栏最大宽度）+ 40px（安全间隙）
2. **视觉舒适**: 有足够的空白分隔
3. **响应式友好**: 在不同屏幕下都有良好表现
