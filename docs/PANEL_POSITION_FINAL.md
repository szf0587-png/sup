# 区域工具面板位置优化 - 最终方案

## 🎯 问题分析

### 原问题
根据屏幕截图，区域工具面板居中显示时：
- ❌ 遮罩层覆盖了左侧的精评配置面板
- ❌ 用户无法同时查看精评配置和使用区域工具
- ❌ 遮罩层过暗（50% 不透明度），完全遮挡背景

### 根本原因
- 精评模块占据左侧固定位置 (`left: 80px`)
- 区域工具面板居中显示会与之重叠
- 全屏遮罩层阻止用户查看背景内容

---

## ✅ 最终解决方案

### 方案：右侧固定 + 轻透遮罩

**核心思路**：
1. 将面板固定在右侧，避开左侧的精评区域
2. 降低遮罩层不透明度，允许用户看到背景
3. 减少模糊效果，保持内容可读性

---

## 📐 具体修改

### 1. 面板位置：从居中改为右侧固定

**修改前**：
```css
position: fixed;
top: 50%;
left: 50%;
transform: translate(-50%, -50%);  /* 居中 */
width: 85%;
max-width: 480px;
```

**修改后**：
```css
position: fixed;
top: 50%;
right: 2rem;                        /* 右侧固定，距离边缘 2rem */
transform: translateY(-50%);        /* 只垂直居中 */
width: 420px;                       /* 固定宽度 */
max-height: 75vh;
```

### 2. 遮罩层：从重度遮挡改为轻度提示

**修改前**：
```css
bg-black/50           /* 50% 不透明度 */
backdrop-blur-sm      /* 较强模糊 */
```

**修改后**：
```css
bg-black/30           /* 30% 不透明度，更透明 */
backdrop-blur-[2px]   /* 轻微模糊，保持可读性 */
```

## 🎯 优势分析

### 1. 避免遮挡
- ✅ 左侧精评配置面板可见
- ✅ 用户可以同时查看两侧内容
- ✅ 不影响工作流程

### 2. 轻度遮罩
- ✅ 30% 不透明度，背景内容可见
- ✅ 轻微模糊（2px），保持可读性
- ✅ 聚焦面板但不完全隔离

### 3. 固定宽度
- ✅ 420px 固定宽度，内容布局稳定
- ✅ 不会因屏幕大小变化而跳动
- ✅ 适合右侧固定位置

### 4. 响应式友好
- ✅ 大屏幕：右侧有足够空间
- ✅ 中等屏幕：面板紧贴右侧
- ✅ 小屏幕：可能需要进一步优化

## 📊 尺寸规格

| 属性 | 值 | 说明 |
|------|-----|------|
| 位置 | `right: 2rem` | 右侧固定，距边缘 32px |
| 垂直位置 | `top: 50%` + `translateY(-50%)` | 垂直居中 |
| 宽度 | `420px` | 固定宽度 |
| 最大高度 | `75vh` | 占视口高度 75% |
| Z-index | `1001` | 确保在最上层 |

| 遮罩层属性 | 值 | 说明 |
|-----------|-----|------|
| 背景 | `bg-black/30` | 30% 不透明黑色 |
| 模糊 | `backdrop-blur-[2px]` | 轻微 2px 模糊 |
| Z-index | `1000` | 在面板下方 |

## 🔄 如果仍需调整

### 如果面板太宽
```css
width: 380px;  /* 从 420px 缩小到 380px */
```

### 如果遮罩层仍太暗
```css
bg-black/20    /* 从 30% 降低到 20% */
backdrop-blur-[1px]  /* 从 2px 降低到 1px */
```

### 如果需要更靠近边缘
```css
right: 1rem;   /* 从 2rem 改为 1rem */
```

### 如果在小屏幕上需要居中
可以添加媒体查询：
```css
@media (max-width: 1024px) {
    #region-tools-panel {
        left: 50% !important;
        right: auto !important;
        transform: translate(-50%, -50%) !important;
        width: 90%;
        max-width: 420px;
    }
}
```
