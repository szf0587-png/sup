## 一、项目概览

### 1.1 一句话定位

**基于 SuperMap iServer 的国产 GIS 土地资源评估与三维可视化工作台** —— 面向政府自然资源部门、科研机构与农业咨询团队，围绕"评估边界"开展逐步空间分析，将每一步的文字结论与地图要素返回同一工作区，实现"选地块 → 出结论 → 生成报告"的一站式决策闭环。

### 1.2 核心价值

| 价值点 | 说明 |
|---|---|
| 数据驱动决策 | 从卫星影像、行政区、水体、道路、DEM 等空间数据自动评估土地适宜性 |
| 全流程闭环 | 金标准建模 → 物候匹配 → 区域筛选 → 地块精评 → 报告生成 |
| 多租户 SaaS | 用户注册登录、数据隔离、项目管理，支持多人协同研究 |
| 国产化技术栈 | SuperMap iServer / iObjects / Realspace 三维引擎，满足信创要求 |
| 深度 GIS 集成 | 34 个 API 打通 5 大模块：空间分析、地图服务、数据编辑、数据管理、三维服务 |

### 1.3 目标用户

- **自然资源局/土地管理部门工作人员** — 快速评估地块适宜性，辅助审批决策
- **农业/遥感研究机构** — 作物适宜性分析、物候匹配研究
- **规划咨询公司** — 区域筛选、地块精评，输出决策报告

### 1.4 品牌基调

- **名称**: 天眼寻珍·苍穹（"天眼"= 遥感卫星视角；"苍穹"= 天地一体、三维空间）
- **风格关键词**: 科技 · 专业 · 可信 · 绿色生态 · 深色沉浸
- **参考产品气质**: ArcGIS Online（专业 GIS）、Mapbox Studio（科技感）、Linear（现代极简）、Climate FieldView（农业科技）

## 二、功能模块全景

### 2.1 用户与平台层

| 模块 | 功能要点 |
|---|---|
| 认证 | 注册 / 登录 / 登出 / 记住我 / 自动登录 / Token 过期处理 / 修改密码 |
| 角色权限 | 普通用户（仅自己数据）/ 管理员（全部数据）；JWT 认证中间件 |
| 项目管理 | 项目 CRUD、激活机制（同时仅一个激活项目）、项目关联数据集 |
| 数据集管理 | GeoJSON / Shapefile / GeoTIFF 上传、元数据自动提取（CRS/边界/字段/波段）、用户目录隔离 |

### 2.2 业务分析层（土地资源评估核心流程）

```
① 金标准建模 ──▶ ② 物候匹配 ──▶ ③ 区域筛选 ──▶ ④ 地块精评 ──▶ ⑤ 报告生成
(专家定义作物     (NDVI/LST 曲线     (Top N 乡镇       (单地块适宜性    (一键输出
 适宜性参数)       匹配相似性)         排序筛选)         综合评价)         决策报告)
```

| 业务功能 | 说明 |
|---|---|
| 金标准管理 | 作物类型、坐标、适宜性参数、物候曲线的增删改查，自动关联激活项目 |
| 物候匹配 | 基于用户金标准的 NDVI/LST 物候曲线相似性匹配 |
| 区域筛选 | 按适宜性权重 0.7 + 物候权重 0.3 综合排名，Top N 乡镇筛选 |
| 地块精评 | 单地块逐项评分，输出适宜性结论 |
| 报告生成 | 自动生成图文决策报告，支持查看历史 |

### 2.3 GIS 分析层（iServer 深度集成 · 34 API）

| 模块 | API 数 | 功能 |
|---|---|---|
| 空间分析 | 8 | 坡度/坡向/山体阴影、核密度/点密度、加权叠加、IDW/Kriging 插值 + 原生算子目录/执行 |
| 地图服务 | 5 | 服务列表/详情、瓦片配置、地图列表、推荐底图 |
| 数据编辑 | 6 | 要素增删改查、ID/SQL 查询、批量属性更新 |
| 数据管理 | 7 | 元数据、数据集列表、字段添加、属性表、GeoJSON/CSV 导入导出 |
| 三维服务 | 6 | 三维场景列表/详情/配置、地形信息、地形生成指南、模型上传 |

### 2.4 3D 三维展示层（Realspace 工作台 · 进行中）

- 深色科技风 3D 决策视图，自动发现 iServer 发布的 `3D-*` / `realspace-*` 三维服务
- 场景/数据集目录解析、SCT 地形（TerrainFileLayer）检测、相机视角自动读取
- 引擎自适应：SuperMap3D（官方 WebGL）→ 回退 Cesium 1.114
- 地图要素：坐标拾取、图层显隐、场景切换、地形夸张倍数调节

## 四、设计规格（Design Spec）

### 4.1 设计原则

1. **专业可信** — 面向政府/科研的严谨界面，避免花哨装饰
2. **数据可视化优先** — 地图和图表是主角，界面 UI 退居次席为其服务
3. **效率至上** — 减少操作步骤，常用操作一键可达
4. **科技感** — 深色沉浸 + 绿色生态科技视觉语言

### 4.2 色彩系统（深色主题为主）

**主品牌色 — 农业绿**（土地/生态/适宜性）

```css
--primary-400: #4ade80;   /* 高亮 */
--primary-500: #22c55e;   /* 主色 */
--primary-600: #16a34a;   /* 按钮/主操作 */
--primary-700: #15803d;   /* hover */
```

**辅助色 — 科技蓝**（信息/链接/科技感）

```css
--secondary-500: #3b82f6; /* 次要色 */
--secondary-600: #2563eb;
```

**背景（深色）**

```css
--bg-primary:   #0f172a;  /* 主背景 slate-900 */
--bg-secondary: #1e293b;  /* 面板/卡片背景 slate-800 */
--bg-tertiary:  #334155;  /* 第三层/悬停 */

```

**语义色**

```css

```

**文字层级**（深色背景上）

```css
标签: #94a3b8 (slate-400)  │  禁用: #64748b (slate-500)
```


### 4.7 交互与动效

```css
过渡: 150ms hover / 250ms 展开收起 / 350ms 复杂动画
缓动: cubic-bezier(0, 0, 0.2, 1) 标准
动效场景: 按钮 hover、下拉展开、模态框淡入、面板滑出、加载骨架屏
```

### 4.8 响应式

- 桌面优先（本产品主要为桌面工作站使用）
- 断点: 640 / 768 / 1024 / 1280 / 1536px
- 最小触摸目标 44×44px（移动端备用）

## 六、技术栈与约束（设计实现参考）

| 层 | 技术 | 设计含义 |
|---|---|---|
| 后端 | Python / FastAPI / SQLAlchemy / SQLite / JWT / bcrypt | — |
| GIS | SuperMap iServer REST / iObjects / iobjectspy | 地图与三维为真实数据服务 |

- 深色主题为主，浅色为可选
- 地图区域永远是视觉中心，UI 不得遮挡地图主体
- 所有颜色/字体/间距必须来自本规格的变量体系
- 兼顾 100% 缩放下的 1440×900 桌面显示
