## 🚀 使用方法

### 打开区域工具
1. 在左侧工具面板找到"区域工具"按钮（图钉图标）
2. 点击按钮打开工具面板

### 目标选择功能
1. 切换到"目标选择"标签页
2. 输入地名搜索 或 输入经纬度
3. 点击搜索/定位按钮
4. 地图会自动定位到目标区域

### 区域管理功能
1. 切换到"区域管理"标签页
2. 点击"重选"按钮（面板会自动关闭）
3. 在地图上点击选择区域
4. 重新打开面板，输入区域名称
5. 点击"保存"按钮
6. 已保存的区域会显示在列表中

### 关闭面板
- 点击右上角的 ✕ 按钮
- 点击面板外的遮罩层
- 执行某些操作后自动关闭（如"重选"）

## 🔧 技术实现

### HTML 结构
```html
<div id="region-tools-backdrop">  <!-- 遮罩层 -->
<div id="region-tools-panel">     <!-- 主面板 -->
  <div>头部</div>
  <div>标签页导航</div>
  <div>标签页内容</div>
</div>
```

### CSS 关键样式
- `fixed` 定位居中
- `z-index: 999` 确保在最上层
- `hidden` 类控制显示/隐藏
- `glass-panel` 毛玻璃效果
- `fadeIn` 动画

### JavaScript 核心函数
```javascript
toggleRegionTools()           // 打开/关闭面板
switchRegionTab(tabId)        // 切换标签页
syncRegionToolsData()         // 同步数据
searchPlaceByNameModal()      // 模态框中搜索地名
applyCoordInputModal()        // 模态框中坐标定位
saveScanRegionModal()         // 模态框中保存区域
```
