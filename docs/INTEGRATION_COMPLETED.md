## ⚠️ 注意事项

### 1. 管理器初始化
新功能需要管理器初始化。在地图初始化后会自动创建管理器实例：
```javascript
window.MapManager = new MapManager(map);
window.DrawTools = new DrawTools(map);
window.LayerManager = new LayerManager(map);
```

### 2. 底图切换
- 点击"地图服务"后会自动加载底图列表
- 如果iServer服务不可用，会显示"加载失败"
- OSM底图始终可用作为备用

### 3. 数据保存
- 绘制的要素保存时需要指定数据源和数据集名称
- 默认数据源：`user_ds`
- 可以自定义数据集名称

### 4. 空间分析
- 分析工具需要数据源中存在对应的数据集
- 例如坡度分析需要DEM数据集
- 分析参数会弹出单独的配置界面

## 🐛 故障排查

### 问题1: 点击按钮没反应
**解决**:
- 打开浏览器控制台（F12）
- 查看是否有JavaScript错误
- 确认管理器是否初始化（看到"✓ 所有管理器初始化完成"）

### 问题2: 右侧面板不显示
**解决**:
- 检查`gis-tools-panel`元素是否存在
- 查看CSS样式是否正确加载
- 尝试刷新页面（Ctrl+F5）

### 问题3: 底图列表加载失败
**解决**:
- 确认后端运行正常
- 访问 http://localhost:8000/docs 测试API
- 检查iServer服务是否可达

### 问题4: 绘制工具不工作
**解决**:
- 确认Leaflet.Draw已加载
- 查看控制台是否有"DrawTools初始化完成"
- 检查地图实例是否正确传递
