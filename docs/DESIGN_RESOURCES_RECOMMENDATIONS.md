## 🎯 针对"天眼寻珍·苍穹"的设计方向建议

### 应该参考的设计风格

1. **深色主题 + 科技感**
   - 参考: ArcGIS Online, Mapbox Studio
   - 配色: 深蓝/深灰背景 + 绿色/蓝色强调色

2. **毛玻璃效果 (Glassmorphism)**
   - 参考: Apple Design, iOS/macOS 界面
   - 实现: backdrop-filter + 半透明背景

3. **数据可视化**
   - 参考: Observable, Plotly Dash
   - 图表库: ECharts (咱们已在用), Chart.js

4. **工具面板布局**
   - 参考: Adobe Photoshop, Figma, Blender
   - 左侧工具栏 + 右侧属性面板

5. **模态框和弹窗**
   - 参考: Linear, Notion, Stripe Dashboard
   - 简洁、居中、毛玻璃背景

## 🔍 如何使用这些资源

### 第一步：寻找灵感
1. 在 Dribbble/Behance 搜索 "GIS Dashboard"
2. 收藏 10-20 个喜欢的设计
3. 分析它们的共同点

### 第二步：分析布局
1. 观察工具栏位置（左侧/顶部/右侧）
2. 观察主要内容区域（地图/表格/图表）
3. 观察次要面板（配置/结果/统计）
4. 观察模态框和弹窗设计

### 第三步：提取配色
1. 使用浏览器扩展提取配色（如 ColorZilla）
2. 分析主色/辅助色/强调色的使用
3. 记录配色的 RGB/HEX 值

### 第四步：参考组件
1. 在 TailwindUI/shadcn/ui 找类似组件
2. 复制代码到项目中
3. 根据设计系统调整样式

### 第五步：迭代优化
1. 先实现基本布局
2. 逐步优化细节
3. 测试用户体验
4. 收集反馈继续改进
