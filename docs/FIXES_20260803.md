## 🎯 修复内容

### 1. 3D地形图层降级方案 ✅

**问题**：地形图层开关无效，iServer未启动时无地形显示

**解决方案**：三层降级策略
```
优先级1：iServer SCT地形（真实洛南县地形）
  ↓ 如果失败
优先级2：Cesium World Terrain（全球在线地形）
  ↓ 如果失败
优先级3：EllipsoidTerrainProvider（平面地球）
```

**修改文件**：
- `frontend/map3d.html` (第318-350行)
  - `createTerrainProvider()` 函数重写
  - 添加try-catch错误处理
  - 添加控制台日志和用户提示

**代码变更**：
```javascript
// 之前：仅尝试SCT地形，失败则返回null
async function createTerrainProvider(engine) {
    if (!state.config?.terrain_url || ...) return null;
    const provider = new engine.SuperMapTerrainProvider({...});
    return provider;
}

// 之后：三层降级，保证总有地形显示
async function createTerrainProvider(engine) {
    // 1. 优先SCT
    if (state.config?.terrain_url && engine === window.SuperMap3D) {
        try { return new engine.SuperMapTerrainProvider({...}); }
        catch { /* 继续降级 */ }
    }
    
    // 2. 降级到Cesium在线地形
    if (engine.createWorldTerrainAsync) {
        try { return await engine.createWorldTerrainAsync(); }
        catch { /* 继续降级 */ }
    }
    
    // 3. 平面地球
    return null;
}
```

**用户体验改进**：
- ✅ iServer未启动时，自动使用Cesium在线地形（有起伏）
- ✅ 显示toast提示："已启用 Cesium 在线地形（非洛南真实地形）"
- ✅ 控制台清晰记录降级过程
- ✅ 不阻塞场景加载
