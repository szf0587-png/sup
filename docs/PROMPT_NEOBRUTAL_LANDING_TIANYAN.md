任务：桌面新建项目，产出单页滚动官网 index.html 介绍**天眼寻珍·苍穹（土地资源评估工作台）**，风格新粗野主义——硬边框、撞色、实心投影、个性拉满，以假乱真。

【高优先级 · 四条总纲】（先于一切执行，且须落实到每个板块）
A1 图标与表情：全站功能图标统一使用 Lucide 图标——以「内联 SVG path 数据」手写进 HTML（lucide 的 path 允许直接内联，属手写 SVG 范畴；严禁 CDN、图标字体、外链或网络请求方式加载）。品牌吉祥物（小虎鲸，可替换为「天眼」卫星/鹰眼主题图形）与艺术图形（评估边界多边形、坐标网格、等高线、水波纹）仍可手绘原创 SVG。界面全程禁止使用任何表情符号（emoji）。
A2 设计标准：对标 Awwwards、FWA、CSS Design Awards 每日最佳网站同等设计品质——作品级完成度、像素级细节、克制而鲜明的视觉记忆点；每一屏都要经得起"截图即获奖作品"的检验。
A3 创意自由度：把浏览器视作交互式艺术画布，跳出传统布局框架（不满足于居中排版的"网页"，而是"数字作品"）——追求先锋视觉风格、实验性排版、流畅物理动效、极具冲击力的文字版式。
A4 沉浸式体验：融合代码与高级渲染逻辑（动画、视差、状态机、Canvas/SVG 渲染、输入响应），打造统一完整的精品页面，做出突破常规 UI 认知、令人惊艳的数字交互体验。

铁律（高优先级，全站强制）：
- 视觉 100% 手写 SVG——Lucide 图标以 A1 方式内联纳入本规则；禁位图、外链、Emoji、图标字体、外部依赖、网络请求；禁圆角、禁模糊柔和阴影、禁渐变堆砌；用粗硬黑边框、高饱和撞色块、实心硬投影（零模糊）与直角切角建立体积感。
- 多用 SVG 艺术字——描边、错位、反白、印章、贴纸、旋转标签，标题区不许只排裸文字。

美术（A2/A3 执行层）：
- 新粗野主义实验室档案风——奶油纸白/纯黑为主底，**科技蓝 #3b82f6 为锚色**（承接原 DeepSeek 蓝的血统），撞入**项目农业绿 #22c55e** 与 1-2 个高饱和亮色（色相与数量你定，全站克制统一）；粗黑硬边框 + 实心投影制造贴纸与图章感，元素可压线、压字、互相叠压；可混入终端等宽与 GIS 数据特稿气质（投影坐标、CRS 编号、经纬度注记）。
- 主角小虎鲸（黑背白肚、白眼斑、高背鳍，可保留为吉祥物，或替换为「天眼」卫星/鹰眼图形），粗轮廓 + 撞色水花/等高线水纹，首屏 Logo 动画即全站记忆点。
- 以 A3 的"艺术画布"眼光审视每一屏：允许画面构图如海报、如装置，而非传统网页块状布局。

排版（A3 执行层）：
- 统一基线网格 + 栏格系统，粗线分隔，像素级对齐但允许刻意撞破；字号大胆跳跃，主标题用大号艺术字；中文主文案 × 英文等宽注记（FIG 编号 / 投影坐标 / CRS / 单位）保留档案感；数字等宽，每张图表带编号、图注与来源行；整体比实验室版稍紧凑——留白收紧、行距压缩、信息密度更高。
- 实验性排版：至少三处刻意破格（错位、越界、竖排、旋转），并允许更大胆的叠压、出血、异形构图（A3）。

动效（A3/A4 执行层）：
- 多且可玩——环境动画、滚动叙事、微交互全覆盖；多数可交互（可拨动分析流程时间线、逐个点亮的空间分析算子、追随鼠标的虎鲸/天眼视线）；至少两处视觉冲击级（首屏虎鲸破水、成本/效率悬殊落差——如 iServer 利用率 20%→85% 的对比冲击）。
- 节奏干脆利落、带物理质量感（惯性、弹性、重量），拒绝绵软缓动（A3 的"物理动效"指有质感的干脆，不是慢速缓动）。
- 用代码与渲染逻辑构建统一沉浸体验（A4）：滚动即叙事、状态联动、一屏一 wow。

验收：
- DevTools 无位图、无圆角、无模糊阴影（实心硬投影除外）；无任何表情符号；功能图标全部为 Lucide 内联 SVG path（无 CDN/字体/外链请求）。
- 撞色准、硬边利、蓝绿点睛，动效丝滑处处可玩。
- 以 Awwwards 评审眼光逐屏过一遍：构图、节奏、完成度、交互惊喜（A2）。

其余——章节结构、艺术字形态、撞色搭配、混搭尺度、隐藏彩蛋与 wow 时刻——自由发挥，越大胆越好。
