# 区域工具面板尺寸优化报告

## 🎯 优化目标

解决区域工具面板与苍穹精评模块重叠的问题

---

## 📊 问题分析

### 重叠原因
1. **精评模块占据空间大**: 
   - 位置: `top:128px; left:80px; right:6px; bottom:6px`
   - 占据了大部分屏幕空间

2. **原区域工具面板较大**:
   - 宽度: 90% (最大 600px)
   - 高度: 最大 80vh
   - 容易与精评模块重叠

3. **Z-index 层级**:
   - 精评模块: z-index: 10
   - 区域工具面板: z-index: 999 (已足够高，但尺寸过大)

---

## ✅ 优化方案

### 1. 缩小面板尺寸

**优化前**:
```css
width: 90%;
max-width: 600px;
max-height: 80vh;
z-index: 999;
```

**优化后**:
```css
width: 85%;
max-width: 480px;    /* 从 600px 缩小到 480px */
max-height: 70vh;    /* 从 80vh 缩小到 70vh */
z-index: 1001;       /* 提高层级确保在最上层 */
```

### 2. 调整遮罩层层级

**优化前**:
```css
z-index: 998;
```

**优化后**:
```css
z-index: 1000;
```

### 3. 保持居中定位

```css
position: fixed !important;
top: 50% !important;
left: 50% !important;
transform: translate(-50%, -50%) !important;
```
