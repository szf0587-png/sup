# 🚀 快速启动指南

## 立即体验新功能

### 步骤1: 确认后端运行

```bash
# 如果后端还没启动，运行：
cd src/tianyan-cangqiong
python server/main.py
```

### 步骤2: 访问演示页面

在浏览器打开：
```
http://localhost:8000/demo.html
```

### 步骤3: 看到的界面

您应该看到：
- ✅ 顶部导航栏："天眼寻珍·苍穹 - 新架构演示"
- ✅ 左侧工具栏（9个按钮，垂直排列）
- ✅ 中央地图（OpenStreetMap）
- ✅ 右上角绿色通知："系统就绪"

### 步骤4: 测试功能

#### 测试1: 底图切换
1. 点击左侧**第1个按钮**（地图图标）
2. 右侧弹出面板，显示"地图工具"
3. 看到底图列表
4. 点击任意底图（如果iServer可用）

#### 测试2: 空间分析
1. 点击左侧**第8个按钮**（图表图标）
2. 右侧弹出"空间分析"面板
3. 看到4个分类：地形分析、密度分析、栅格分析、插值分析
4. 点击"坡度分析"
5. 看到参数配置表单

#### 测试3: 绘制工具
1. 点击左侧**第2个按钮**（铅笔图标）
2. 右侧弹出"绘制工具"面板
3. 点击"绘制多边形"
4. 在地图上点击绘制（双击完成）
5. 点击"保存到数据集"

## 🐛 故障排查

### 问题1: 页面空白
**解决**: 
- 打开浏览器控制台（F12）
- 查看是否有JavaScript错误
- 确认后端运行在 http://localhost:8000

### 问题2: 左侧工具栏不显示
**解决**:
- 刷新页面（Ctrl+F5）
- 查看控制台是否有"✓ 左侧工具栏初始化完成"

### 问题3: 点击按钮没反应
**解决**:
- 查看控制台是否有错误
- 确认右侧面板是否打开（可能在屏幕外）

### 问题4: API调用失败
**解决**:
- 确认后端运行
- 访问 http://localhost:8000/docs 测试API
- 查看控制台网络标签

```bash

```

```bash
curl http://localhost:8000/api/3d-services/scenes/list
```
