## 📈 技术栈

### 后端
- **Web 框架**: FastAPI 0.x
- **ORM**: SQLAlchemy 2.x
- **认证**: PyJWT
- **密码加密**: bcrypt
- **数据库**: SQLite（可升级到 PostgreSQL）
- **文件上传**: python-multipart

### 前端
- **基础**: HTML5 + CSS3 + JavaScript（原生）
- **样式**: Tailwind CSS
- **地图**: Leaflet.js
- **图表**: ECharts, Chart.js
- **图标**: Font Awesome

### 地理空间
- **矢量处理**: fiona（可选）
- **栅格处理**: rasterio（可选）
- **GEE 集成**: earthengine-api, geemap
- **SuperMap**: iobjectspy
